## О проекте

**Shift Unlocker** — портативная утилита экстренной помощи для борьбы с последствиями заражения вредоносным ПО (винлокеры, блокировщики системы, перехватчики оболочки и повреждения реестра). Программа собрана в **один автономный `.exe` файл** (см. раздел **Releases**) и не требует установки.

### Ключевые особенности
- **Работа без прав и с правами администратора**: при запуске запрашивает повышение привилегий UAC; при отказе запускается в безопасном режиме с автоматической блокировкой недоступных функций и кнопкой быстрого повышения прав.
- **Защита от киллеров (Anti-Kill)**: клонирование исполняемого файла под случайным 17-символьным именем и патч ресурсов версии PE, чтобы вредоносное ПО не могло закрыть утилиту по имени процесса или заголовку окна.
- **Online & Offline (WinPE / WinRE)**: автоматическое обнаружение установленных ОС Windows на дисках и прямая работа с офлайн-кустами реестра (`RegLoadKey` / `RegUnLoadKey`).
- **Откат и карантин**: резервное копирование изменяемых ключей реестра и файлов с возможностью отката (**Undo**) и изолированным карантином (`SU_Quarantine`).

## Модули программы

| Вкладка | Горячая клавиша | Возможности |
| :--- | :---: | :--- |
| **Обзор / Скан** | `Alt+1` | Быстрая диагностика IFEO-перехватов, `Winlogon`, ассоциаций `.exe`, прокси и системных политик в 1 клик. |
| **Автозагрузка** | `Alt+2` | Сканирование `Run`/`RunOnce`, `Winlogon`, `BootExecute`, `IFEO`, папок автозагрузки и планировщика задач (`System32\Tasks`). Эвристический поиск угроз, отключение, удаление и карантин. |
| **Диспетчер задач** | `Alt+3` | Управление процессами (завершение, дерево процессов, заморозка, Watchdog-киллер по имени), службами и сетевыми соединениями. |
| **MBR / Загрузчик** | `Alt+4` | Чтение 0-го сектора (Hex-дамп MBR), анализ аномалий, бэкап/восстановление MBR, `bootsect`, `bcdboot`, офлайн `SFC`/`DISM` и управление томами/дисками (`DiskPart`). |
| **Разблокировка** | `Alt+5` | Снятие и установка ограничений (диспетчер задач, `regedit`, `cmd`, UAC, Defender, USB, скрытые файлы), **пользовательские правила реестра**, фикс шрифтов/темы Aero/русской кодировки CP1251, **замена и восстановление `sethc.exe` и `Utilman.exe`**, управление пользователями и сброс паролей. |
| **Утилиты** | `Alt+6` | Лаунчер встроенных системных инструментов, запуск `sfc /scannow`, управление дисками, добавление/удаление своих `.exe` и запуск утилит под случайным именем. Включает вшитые сторонние инструменты. |
| **Редактор реестра** | `Alt+7` | Прямой редактор реестра (Online и Offline кусты), быстрые закладки, получение прав (`Take Ownership`), экспорт и импорт `.reg`. |
| **Проводник** | `Alt+8` | Независимый встроенный файловый менеджер с деревом папок, историей навигации, просмотром хешей (MD5/SHA256) и PE-заголовков, снятием атрибутов `Hidden`/`System`, `Take Ownership` и принудительным удалением заблокированных файлов. |
| **Мастер и Журнал** | `Alt+9` | Профили автолечения (безопасное / полное), очистка `hosts`, сброс политик, журнал всех действий с откатом и экспорт отчёта в HTML/TXT. |

## Сборка из исходников

Требуется **.NET SDK** (целевая платформа `net11.0-windows`, `win-x64`).

```powershell
# Запуск тестов и сборка единого автономного exe в папку dist\
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
